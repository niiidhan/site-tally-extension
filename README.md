# SiteTally

A minimal Chrome extension that tracks the websites you visit and shows how many times you've opened each one.

## Features

- **Visit counts per site**, sorted most-visited first
- **Filters:** Today / This Week / All Time
- **Per-site detail** — click any site to see the date & time of every visit
- **Counts once per open**, not per page — browsing within the same site doesn't inflate the count; leaving and returning does
- Clean, Linear-inspired dark UI

## Install

1. Clone or download this repo
2. Open `chrome://extensions`
3. Enable **Developer mode** (top-right)
4. Click **Load unpacked** and select the project folder

## Privacy

Everything is stored locally in your browser (`chrome.storage`). No data ever leaves your device.
